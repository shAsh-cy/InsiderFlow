## 2. Issues Identified & Fixed in PR #9 (`chore/final-e2e-verification`)

1. **Daily Supply-Chain Failure Email Root Cause (`supply-chain.yml`):**
   - **Diagnosis:** `osv-scanner-action@v2.2.4` failed on every daily cron run because it scanned the entire lockfile without knowledge of documented devDependency ignores, tripping exit code 1 on `braces` (CVE-2026-93687) and `vitest` (GHSA-82fw-gwwq-j7x9).
   - **Fix:** Added `osv-scanner.toml` at repo root explicitly ignoring both advisories with documented rationales matching `package.json`'s `auditConfig.ignoreCves`. Workflow run 38787263074 is now 100% green.

2. **Changelog Git History Missing on CI Runners (`ci.yml`):**
   - **Diagnosis:** `actions/checkout@v4` defaulted to `fetch-depth: 1`. Step `pnpm lint:changelog` failed because shallow clones cannot verify commit SHAs. In addition, commits for abandoned round `r10` resided on an annotated tag (`abandoned/ui-ledger-r10`) that had never been pushed to GitHub.
   - **Fix:** Pushed tag `abandoned/ui-ledger-r10` to `origin` and added `fetch-depth: 0` to the checkout step in `ci.yml`.

3. **CI Playwright Auth Invariants & Rate Limiting:**
   - **Diagnosis:** In CI, `NEXT_PUBLIC_SUPABASE_URL` was unset (as `.env.local` is gitignored), and default rate limiting capped requests at 60/min. Parallel Playwright workers tripped 429 status codes on stream endpoints, and `account-chip.spec.ts` lacked an explicit skip for unconfigured auth.
   - **Fix:** Provided public development Supabase URLs and `RATE_LIMIT_PUBLIC_PER_MIN: "600"` in `ci.yml` `e2e` job env. Added `authConfigured` check in `account-chip.spec.ts` matching `auth.spec.ts`.

4. **Linux Font-Rendering Layout Shift (`shortcut-hint.tsx`):**
   - **Diagnosis:** On Ubuntu CI runners, the mono font rendering for "Ctrl K" measured ~51.34px, slightly overflowing `min-w-12` (48px) and causing a 3.34px width shift when hydrated to "⌘K".
   - **Fix:** Increased minimum width to `min-w-[52px]`, eliminating layout shift across all operating systems.
